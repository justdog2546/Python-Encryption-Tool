HOW TO RUN THIS CODE?
=================

pleas to run this code use ``Python 3.15.2`` to run this code

(only v.1.0-alpha or later) first you must be run this command:

	$ python -m pip install -r requirements.txt

or

	$ python -m pip install cffi cryptography pycparser
	
And You can run ``Python-Encryption-Tool`` using the following command:

	$ python ./PET
